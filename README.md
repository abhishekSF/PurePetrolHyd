# PurePetrol Hyd

Map of Hyderabad pumps that sell ethanol-free / 100-octane petrol: Indian Oil XP100, BPCL Speed 100, and HPCL poWer100.

This is premium fuel, not regular petrol. Availability changes. Confirm at the pump.

[purepetrolhyd.in](https://purepetrolhyd.in)

## Features

- Map and list of stations across Hyderabad
- Search by area or phrase (`XP100 near Madhapur`)
- Filters for grade, brand, and 24-hour pumps
- Near me, call, and directions
- Report a pump so the list can stay current

Station data is crowd-sourced from the r/hyderabad community and other public reports.

## Run

```bash
npm install
npm run dev
```

Station rows live in `src/data/stations.ts`.
